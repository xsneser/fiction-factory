# 多平台热榜接口设计（2026-09-01）

> 目的：统一多平台（番茄/起点/晋江…）热榜拉取的接口契约，让外部书库页热榜「能显示」，
> 并让新平台只加一个适配器即可接入，不动接口层。GitHub 调研结论与反爬/编码坑见文末。
> 代码权威：`plugins/hot_ranks.py`（注册表）、`plugins/fanqie_scout.py`（番茄实现）、
> `ui/web_blueprints/tools.py`（Web 端点）、`agent_tools.py`（MCP 工具）。

## 一、背景：为什么热榜显示为空

原番茄热榜走两个已失效路径：
- `GET https://fanqienovel.com/api/author/library/book_list/v0`（旧 `_api_hot_list`）→ **404**；
- `GET /rank/hot`（旧 `_web_hot_list`）→ 失效（真实榜单页是 `/rank/{gender}_{rankMold}_{category_id}`）。

已实测可用的新路径：榜单页 `https://fanqienovel.com/rank/1_2_258` 的 SSR
`window.__INITIAL_STATE__.rank`：
- `rank.book_list`：榜单书（bookId/bookName/author/abstract/wordNumber/read_count/currentPos/rankPosDiff/curent_category_id…）；
- `rank.rankCategoryTypeList.male/female`：分类 id↔name（男频 19 个，如 传统玄幻258/都市日常261/科幻末世8/历史古代273/东方仙侠1140/西方奇幻1141）；
- **书名/简介是 PUA 字体加密**，现有 `plugins/font_decoder.py` 的 `FanqieDecoder.decode_content` 可 100% 还原（实测 PUA 174→0）；
- **没有「全部」榜单**：`/rank/1_2_0` 返回 `book_list: undefined`，空分类默认回退第一个分类 → 「全部」用聚合。

## 二、统一条目模型（HotRankItem）

```json
{
  "platform": "fanqie",
  "rank": 1,
  "book_id": "7362544544950275134",
  "title": "西幻：从鹰人部落到天使帝国",
  "author": "枫潇呀",
  "genre": "传统玄幻",
  "word_count": 3242424,
  "chapter_count": 0,
  "hot_score": 463252,
  "intro": "…（已解码简介）…",
  "url": "https://fanqienovel.com/page/7362544544950275134",
  "cover": "https://p3-reading-sign.fqnovelpic.com/novel-pic/…~tplv-resize:225:0.image"
}
```
- `hot_score` 口径随平台（番茄=在读量 read_count；起点=月票/推荐[可能有 woff 混淆→置 0]；晋江=收藏/积分）；
- 代码载体：`plugins/fanqie_scout.py` 的 `NovelInfo` dataclass 增补 `cover` / `platform` / `rank` 三个默认字段（全兼容旧调用），适配器输出 `n.__dict__`。

## 三、平台注册表（plugins/hot_ranks.py）

```python
class BaseHotRanker:
    PLATFORM = ""
    def list_rankings(self, **kw) -> list[dict]: ...   # [{id, name}]（供 UI 下拉 / 动态 chips）
    def discover(self, key="", count=10, **kw) -> list[dict]: ...  # [HotRankItem dict]

REGISTRY = {"fanqie": FanqieRanker(), "qidian": None, "jjwxc": None}

def discover(platform="fanqie", key="", count=10, **kw) -> list[dict]
def list_rankings(platform="fanqie", **kw) -> list[dict]
```
- `key` 语义：番茄 = 榜单分类 id（或题材中文名，空/'全部'=聚合）；起点 = 榜单 id；晋江 = orderstr。
- 未知平台 / 未实现 / 抛错 → 返回空列表（UI 显示「暂无热榜数据」兜底）。

## 四、Web 端点（ui/web_blueprints/tools.py）

- `GET /api/scout/hot?platform=fanqie&key=<分类id|题材名>&gender=male&rank_mold=2&count=10`
  - 兼容旧 `?genre=<中文名>`（key 缺省回退 genre）；
  - 返回 `{ok, platform, key, novels:[HotRankItem…], ts, refreshing|loading}`；
  - 缓存：`storage/hot_cache.json`，键 `platform:gender:key`，TTL 600s；过期/缺失 → daemon 线程后台拉取 + 立即返回状态（页面轮询直到 novels 出现）。
- `GET /api/scout/hot/rankings?platform=fanqie&gender=male`
  - 返回 `{ok, platform, gender, rankings:[{id,name}]}`（缓存 10min）。

## 五、MCP 工具（agent_tools.py）

- `discover_hot(platform="fanqie", key="", count=10)` — 扩参，走注册表；
- `list_rankings(platform="fanqie", gender="male")` — 新增，查榜单/分类清单；
- 工具数 35 → 36，`tools/mcp_smoke.py` 的 `EXPECT_MCP_TOOLS` 与在列断言已同步。

## 六、番茄实现要点（plugins/fanqie_scout.py）

- `discover_hot(key, count, gender, rank_mold)`：key 中文名 → `GENRE_CATEGORY` 映射到分类 id（玄幻→258…）；纯数字 id 直接用；空/'全部' → `_rank_aggregate` 聚合头部分类（258/261/8/273/1140/1141 各取前 5，按 read_count 排序取 count）。
- `_rank_by_category`：GET `/rank/{gender}_{rankMold}_{id}` → `_extract_ssr`（`undefined`→`null` 后 raw_decode 解析）→ `rank.book_list` → `_novel_from_rank`（书名/作者/简介 `FanqieDecoder.decode_content` 解码；read_count→hot_score；currentPos→rank；wordNumber→word_count）。
- `list_rankings(gender)`：从任一榜单页 SSR `rankCategoryTypeList` 取分类清单（各页一致）。
- 已删除死代码：`_api_hot_list`（404 老接口）、`_web_hot_list`（失效页）。

## 七、前端（ui/templates/scout.html）

- 平台 tab：🍅番茄（可用）/ 起点 / 晋江 / 网页（禁用占位）；
- genre chips：全部/玄幻/都市/科幻/历史/仙侠 → 后端映射分类 id，「全部」= 聚合；
- 热榜条目新增「第 N 名」徽标（rank），保留 🔥 热度（在读量）。

## 八、平台接入要点（调研结论，新适配器照此实现）

| 平台 | 数据来源 | 坑 |
|---|---|---|
| 起点 qidian | `m.qidian.com` 移动站 SSR（requests），或 Playwright（d3nnywong/qidian-mcp-server：14 榜 × 品类） | 月票/推荐数字为 **woff 字体混淆**（需解析 cmap 映射还原；否则 hot_score 置 0，仅排名/标题/作者）；动态渲染 + 风控，控制频率 |
| 晋江 jjwxc | `https://www.jjwxc.net/topten.php?orderstr={榜ID}&t={频道}`（t=0 全站）；列表取 novelid → `onebook.php?novelid=` 详情补收藏/营养液/积分/字数（itemprop 微数据，无需登录） | 页面 **gb18030** 编码（`fetch+arrayBuffer+TextDecoder('gb18030')`）；榜 ID：收入金榜12/月榜7/季度榜8/完结金榜14/新手金榜15/千字金榜17 |

GitHub 参考：`fanqie-rank-mcp`（番茄榜单 MCP，ranking_id=`性别_榜单类型_分类ID`）、`staysharp1104/WebCrawler`（多平台榜单混合抓取）、`FanqieAllRankTracker`（男频/女频 × 阅读/新书榜）、`qidian-mcp-server`、`dev-chenxing/jjwxc-charts`。
