# 交接文档：深化并入步3生成——提交即 phase=ready，删除后置深化阶段

> 日期：2026-09-05　提交：5679592 / 966a3eb / 296e2e9 /（本文档）　范围：dsh/平台侧 + Claude 侧 skill 措辞
> 一句话：**新书不再「submit→plots 草案→自动深化→书详情确认→ready」**——步 3 生成时就把深化一次做完（差异化命题 `world_building.differentiation` 随 `set_world` 内联落库 + 每弧 notes + 内联 `validate_storyline` 回打≥1轮），用户浏览器点提交即 **phase=ready**，无书详情二次确认、无任何后置深化任务/按钮。`plots`/`confirm-storyline` 仅保留给 config/补弧失败兜底与遗留恢复。
> 取代：`docs/交接文档-2026-09-04-故事线草案评审门与研究式深化.md` 的「提交后深化段」部分（其 plots 草案评审门/ready-仅用户确认护栏精神保留，落点从书详情确认门改为「用户点提交建书即解锁」）。

## 一、背景与动机

2026-09-04 引入的「plots 草案评审门 + submit 后研究式深化」经真实走查（book_002《2050：星海重开》2026-09-05 10:27–10:50 全链路轨迹，见 `storage/task_events.jsonl`）被证明环节冗余：

- **步 3 本就能产出深化质量内容**：走查里 step3 生成已含每弧 notes（目标+偏离库模板点）、差异化四段论述、内联 `validate_storyline` 回打一次修到 79 桥段通过。提交后单独派发的深化段几乎无增量。
- 用户判定：**深化与第三阶段生成是一件事**，不该 submit 后再单独深化一次。

## 二、目标形态（新书故事线流）

```
步3 深化式内容构建（差异化命题：core_conflict(最核心一条) + world_building.differentiation(全量论述) 随 set_world 内联落库
  → 势力 → 弧+桥段(每条 notes=「本弧目标 + 偏离库模板 X 的点」，set_outline 落表) → 人物 → 其余维度
  → 内联 validate_storyline(outlines/plots) + validate_world(basic_info) 回打≥1轮直到 passed=true → 汇报故事线蓝图)
→ 用户在向导点「提交建书」（agent 不调 submit）
→ dashboard start_new_book：fill_themes_and_hooks + annotate_plot_roles + phase=ready（无 ?newdraft、无 plots、无书详情确认门）
→ novel-story 写作解锁
```

config/补弧失败兜底（step3② 弧没带上）：submit 落 `config` → agent 自主生成 outlines/plots（含 notes）经 `save_outlines` 落盘 → phase=plots → 用户在书详情点「✅ 确认弧+桥段」（`/api/book/<id>/confirm-storyline`，保留为 legacy 恢复端点）→ ready。

护栏保持：**ready 始终由用户动作触发**（正常=用户在向导点提交；兜底=用户在书详情确认）；agent 无 fill_gags/confirm_outlines 等翻 ready 工具。

## 五、护栏（agent 视角，务必遵守）

1. **ready 无 agent 工具**：新书 phase=ready 来自用户在向导点提交（agent 不调 submit）；config/补弧兜底书停在 plots 时只能 `save_outlines`/`validate_storyline` 迭代并引导用户在书详情点确认，不得臆造翻转。

## 六、坑 / 注意

- **`differentiation` 随 `set_world` 落库的两条链**：`set_world` handler（`start_book.html` ~L1331）把任意 world_building 键并入 `state.world_building`；`worldToBi()`（~L993）现从 state 透传 `differentiation` 键，`collect()` 重建 state.world_building 时不再丢它。服务端 `dashboard.py` 对 world_building 只 `setdefault` 不 strip，落库无损。
- **书详情世界编辑表单（_world_edit_form）不展示 differentiation 字段**：ready 后用户在该表单编辑世界观保存时会静默丢该文档（沿用 description/tags 之外自定义键的既有缺口，本次未扩范围；如需可另开任务加只读展示）。
- **已 ready 书续写/扩写追加弧保持 ready**：`save_outlines` 该语义是删 fill_gags 时的必要前提，保留勿回退；深化并入步3 后 save_outlines 对 config/未 ready 书补弧仍落 plots（供兜底确认）。
- **旧 plots 书/历史文档**：09-04 交接文档、架构/分析/设计三份旧文档为历史快照，未重写（列出旧 plots 草案/深化属历史，勿当现行契约）；真到期的 plots 书可经保留的 confirm 端点恢复。
