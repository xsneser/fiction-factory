## 四、核心概念速查

- **风格规则库**：禁句式/去AI词表从「改源码」变为「改 `/style-rules` 页」，`style_rules.jsonl`（`libraries/data/`，gitignore）持久化；无文件 = 内置种子，有文件 = 用户覆盖（**消费方实时生效**，无需重启）。
- **快照**：写类工具落库前自动留底（`_wrap_book_lock`）；回滚前再留一次底防误回滚；MCP `preview_diff`/`rollback_book` + 书详情「历史快照」面板。
- **六操作分级**：`promise_op(q, chapter_num)` 规则层定 seed/touch/pressure/partial_reveal/payoff，随章节推进在 `_update_promises_ledger` 演化，注入 `_promises_block`（【伏笔·<操作>】标签）。
- **repair_stalled**：自评/生成连续失败达 `REPAIR_STALL_THRESHOLD=3` → yield 事件；engine 保留进行中草稿停下；写作台 gen-feed 显示 decision 卡。与 `budget_paused` 同一模式。
- **gen-feed**：写作台手动驱动引擎逐桥段（SSE `/api/storyline-engine/<engine_id>/write-bridge`）；成功写完 `location.reload()`，暂停/异常保留事件卡。agent（侧栏 dsh）驱动时该 feed 不实时跟（事件在侧栏工具卡）。
- **`tools/verify_storyline_redesign.py`**：改动 `story_line.js` 后跑的回归（Gantt 渲染/无 console 错误/交互冒烟），book_002 为断言数据源。

## 六、已知坑 / 注意事项

1. **58080 必须重启才生效**：Flask reloader 在蓝图 import 报错后可能停更——改了 `web_blueprints/` 或 `ctx.py` 后，手动 Ctrl+C → `launch.bat`。全站已发现两处可致 reload 崩溃的坑（都修了）：ctx 单例漏加 `__all__`、`JsonLibrary` 子类漏 `_from_dict`。
2. **新库页样板**：四大库/风格规则库的 `JsonLibrary` 子类必须实现 `_from_dict`（classmethod），否则持久文件存在时 `_load_jsonl` 崩溃；ctx 加单例要同步加 `__all__`。
3. **写类工具自动快照**：`_wrap_book_lock` 里每个写工具落库前 `copytree` 整书目录（保留 10 份，`_prune` 自动清理）——快照失败不阻断写操作；大书频繁写会有 IO 开销，可考虑只快照核心 JSON。
4. **`storyline_outline_card.html` 已删**：孤儿模板（无 include/渲染路径），`base.css` 的 `.outline-card/.oc-*/.outline-overlap/.btn-sm` 死样式一并清除；README 目录树已同步。
5. **`.research/`（6 个竞品克隆仓库）与 `tools/shots_ux/` 已 gitignore**；2 份竞品文档与 `tools/shot_storyline_redesign.py` 保持未跟踪（如要入库需自行决定）。
6. **book_002 卡 config**：写作台规划态（有 outline/plots 但 phase 未 ready）；质量诊断/承诺台账/审查对其部分显示「空」是数据所致，非 bug。要写作先解锁大纲（见既有记忆 `book-002-stuck-config`）。
