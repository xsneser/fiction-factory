第一波升级已落地（2026-08-27）：数据模型 `OutlineSlot.parent_arc_id` 弧树嵌套、契约「order 弧内序号」、UI 弧树/设局→收局连线/线程泳道/narrative 目标/缺 id 容错，`test_all.py` 97/97。但用户在验收中发现三处未闭环：

### Part 5 — UI 章节轴改造（`ui/static/js/story_line.js`，唯一改动文件）
**坐标约定**：`start/end` 半开区间语义保留，单位换 **0-based 章节槽位**（第 N 章占 `[N-1,N)`）。弧 `[s,e]`(1-based 含端) → `o.start=s-1`、`o.end=e`。`chapterToPercent(ch)=ch/TOTAL_CHAPTERS*100`（过原点线性，`height=chapterToPercent(end-start)`、`mid=(start+end)/2` 公式全部不变，只换函数名）。

1. **模块级**：`TOTAL_WORDS`→`TOTAL_CHAPTERS`；`wordToPercent`→`chapterToPercent`（定义 + 16 处调用：renderAxis/renderOutlines/renderPlots/renderThreads/renderCursor + 弧父连线 355-356 + 桥段父连线 516-517 + 设局线 540-541 + thread relTop 612 的 3 处）。删 `plannedWords`；`WPC` 保留仅作 header「每章约 N 字」meta。
2. **adapt()**：outlines map 丢弃 `ow`/`plannedWords`，携带 `start_ch/end_ch`（真实跨度）；删游标累计循环 → `TOTAL_CHAPTERS=max(end_ch)`、`o.start=start_ch-1`、`o.end=end_ch`。新增 `arcChapters(o)` 缺省防御（全缺→[1,30] 后端默认；只缺 start→1；只缺 end/start>end→单章），杜绝 NaN 坐标。plots 删 `cum` 字数累计 → 弧内按序比例均分 `start=oStart+(i/n)*span`、`end=oStart+((i+1)/n)*span`（span≥1、n≥1 无除零）。threads 空线程默认 `end=1`。
3. **renderAxis**：刻度换章节，`step=max(1,ceil(TOTAL_CHAPTERS/20))`，label「第N章」，末章兜底刻度（第 N 章刻度线 = 该章顶边，与弧 bar 顶边精确对齐）。
4. **renderCursor**：`ch=clamp(currentChapter,1,TOTAL_CHAPTERS)`，`y=chapterToPercent(ch-1)`（去 ×WPC 折算）。
5. **scrollable 高度**：`totalCh=max(1,TOTAL_CHAPTERS)`。
6. **header meta**：「总章节数 N · 大纲 N · 桥段 N · 线程 N」。
7. **tooltip 文案**（3 处）：「字数/N字」→「章节/第 X—Y 章」（renderOutlines 用 1-based start_ch/end_ch；renderPlots/renderThreads 用 `Math.round(p.start+1)—Math.round(p.end)`）。
8. **不动**：合成 id/映射/resolvePlotId/setupIds/promises/threadPalette/assignLanes/barCenterX/arcCenterX/levelBlockW/highlight/scrollTo（与坐标正交）。

**回归项**：book_001 全 [1,30] 重叠→lane 并排 5 列；book_002 顺序弧相接无 1px 缝；无桥段弧最小高可见；跨弧设局线长距衰减；缺/非法章节不产生 NaN/负高；cursor 越界钳制；TOTAL=1 空书不崩；grep 复核 `wordToPercent|TOTAL_WORDS|plannedWords` 归零；正交部分零改动。
