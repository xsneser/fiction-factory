## 一、接手时状态（codex 已完成，接手 Agent 已复核）

codex 在额度耗尽前已把核心改造 Wave A–D 全部落地，接手 Agent 逐项核对代码并确认实现完整：

1. **Planning State 聚合接口与面板**
   - 新增 `GET /api/storyline/<book_id>/planning-state`（`ui/web_blueprints/storyline.py`），纯读聚合 `planning_state.json` + `storyline.json` 摘要 + 后端计算的 boundary + 未提交的 replan_preview。
   - 新增 `libraries/planning_state.py`：默认状态、patch 校验、合并、boundary 检测（PLOTS_LOW / WORDS_LOW + 同版本防抖）、replan 预览持久化/丢弃、建书草稿会话。
   - 书详情页与写作台均挂载可复用规划面板 `ui/templates/_planning_ui.html` + `ui/static/js/planning_ui.js`：已写/已承诺/可执行 plots + Revision、H0/H1/H2、开放问题、人物意图、最近续规划；无规划数据的旧书显示空态不报错。

2. **Gantt 双区展示**（`ui/static/js/story_line.js`）
   - `StoryLine.init(mountId, bt, options)` 新增 `planning` / `boundary` 参数，旧调用兼容。
   - `renderBoundary()`：承诺边界琥珀虚线（黄线=决定到哪里），与红色写作光标并存。
   - `renderForecast()`：承诺边界下方斜纹 Forecast 区，只渲染 H1/H2/Open Question/Character Intent 卡，**不渲染任何带 plot_id 的条**；图例明确实色=已承诺、斜纹=可变未来、红线=写到哪里、黄线=决定到哪里。

3. **Boundary 与用户确认式 Replan**
   - 写作台 `#boundary-banner` 消费后端 boundary（分级 warning/critical），按钮触发 replan 任务。
   - `drive_ui` 新增仅限 replan profile 的 `set_replan_preview` 子命令（`libraries/agent_tool_router.py` + `agent_tools.py`），Agent 只写独立预览文件（`replan_preview.json`），不修改 storyline / planning state；校验含 expected_revision（必须等于当前故事线版本）、2–3 方向、6–12 plots（批次策略 REPLAN_BATCH_MIN/MAX）、结构校验、validate_storyline。
   - 半屏抽屉 `#replan-drawer`：诊断 → 候选方向（单选/重拟）→ 待提交情节段 → 确认/丢弃；每份预览带唯一 preview_id，刷新可恢复。
   - 新增 `POST /api/storyline/<book_id>/commit-plan`：校验 preview_id 与 expected_revision → BookLock → 复用 `save_outlines`（append + expected_revision）原子提交 → 成功后删除预览并返回新状态。
   - 新增 `DELETE /api/storyline/<book_id>/replan-preview/<preview_id>`。
   - `novel-replan` skill（`.claude/skills/novel-replan/` 与 `agent-sidecar/skills/novel-replan/`）明确要求 Agent 不得直接调 `save_outlines`，只能暂存预览。

4. **Plot Run 与人物变化**
   - `PlotSlot` 新增兼容可选字段 `execution_brief`（dict）、`character_impact`（list），旧故事线缺失按空值处理。
   - `agent_tools._build_plot_run` 返回 execution_brief / character_impact；写作台 `renderPlotRun()` 展示戏剧目标/冲突来源/人物选择/不可逆变化/读者问题/结尾钩子 + 写前人物影响预测折叠区。
   - 章节轮询接口 `/api/desk/chapters/<book_id>` 返回 `recent_plot_outcome`（从最近完成 draft bridge 的 character_events 取实际，按 plot_id 找回写前预测）；写作台展示「预测 → 实际 → 结果」对照，且随轮询局部刷新（保留阅读器页码与高亮）。

5. **Revision 冲突与安全提交**
   - 提交瞬间重读磁盘 revision（`save_outlines`），陈旧时返回 `stale_storyline`（expected/actual），`commit-plan` 映射为 409；两个正式文件均不被修改。
   - `_planning_ui.html` 内嵌全局冲突弹层（保留预览 / 刷新并重新规划）；`planning_ui.js showConflict()` 驱动。
   - 结构校验或 planning_patch 校验失败时，正式 storyline 与 planning state 保持不变（`save_outlines` 在副本上完成全部变更与校验）。
