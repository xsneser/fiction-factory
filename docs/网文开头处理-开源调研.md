> 调研日期：2026-08-05

## 二、行业「黄金三章」共识（各平台编辑口径）

- **前 300 字 = 黄金窗口期**：第一句就要有动作或对抗，短句（每行 ≤17 字），人物 ≤2 个，聚焦一个动作现场，背景设定一句带过。
- **节奏公式**：0–300 字突发危机（死亡/背叛/超自然事件）→ 300–800 字主角反击（打脸/绑系统/发现秘密）→ 800–1500 字设长期悬念。
- **三章分工**：① 主角入局、异常出现 → ② 阻力加压、规则露出 → ③ 主线承诺、目标/代价确立。
- **番茄（快爽平台）**：前 1000 字内完成「冲突 → 主角登场 → 目标浮现 → 钩子落地」；金手指最晚第 1 章；人设可标签化（护短/记仇/苟王/欧皇）。
- **起点（硬核平台）**：允许适度铺垫，但每段都服务人设或伏笔；金手指最晚第 3 章；冲突更有层次；签约看「三章 + 大纲」。
- **章末断章四式**：决定（不可撤回的选择）、发现（旧事实的新解释）、误判（读者知道角色正走向错误答案）、代价（目标刚达成、更大账单出现）。
- **钩子递进三方向**：风险更具体（模糊不安→明确威胁）、关系更贴身（陌生事件牵到主角自己）、选择更难撤回（旁观→承担代价）。
- **主角铁律**：第一章主角必须出场且**受不公平伤害**，用「一个核心动作」立住人设；禁止「善良隐忍 / 舔狗 / 圣母 / 长时间窝囊」。
- **新手必避三坑**：堆砌设定手册（要用剧情带设定）、主角缺位或人设模糊、钩子断层（第一章钩子第二章不呼应）。

## 三、NovelEngine 现状（`OPENING_MODE_RULES`，`prompt_harness.py:61`）

作用域：**第一章前 800 字 / 前 3 个桥段**强制启用「炸裂开场」。

9 条铁律：
1. 冷开场：前三句直接进入冲突/反转/对话，禁止铺垫环境、天气、世界观、人物背景。
2. 第一句话就要制造悬念或冲击。
3. 前 200 字必须有强烈钩子；开篇前 500 字必须有冲突或危机（番茄要求）。
4. 前 500 字必须触发主角的第一个危机/矛盾。
5. 若有金手指/能力，本章内必须引入或激活。
6. 微观结构：[冲击性画面/对话] → [快速解释发生了什么] → [抛出问题]。
7. 示例节奏（闹钟/纳斯达克/被踹下台式冲击开场）。
8. 禁止：天气/环境长铺垫、「他醒来，阳光洒在脸上」式平淡开头。
9. 冲突线前置：开篇直接把核心冲突拍在读者脸上，与主角困境同屏立起。

配套机制：
- `platform_constraints`（`book_meta.py`）：番茄 → 前 500 字必须有冲突/危机、章末必须有钩子、对话 ≥30%。
- `reviewer.py` 规则审查：章末钩子检查（末尾 200 字无钩子信号报警）。
- `hook_points`（吸睛点）：每个桥段注入「⚡ 吸睛」引导。
- `_pre_write_diagnosis` 写前诊断：读者此刻欲望 / 本节最强爽点 / 敌人可见损失 / 章尾追更理由。

**对比结论**：NovelEngine 的规则已覆盖「冷开场 + 前 200/500 字 + 金手指本章引入 + 冲突线前置」，在开源工具里属**中上水平**；主要差距在于「分阶段字数里程碑」「钩子类型化」「三章钩子链条」「钩子示例库」「主角铁律」「章末钩子不重复」六点。

## 四、可借鉴的改进点（均属 prompt / 免费规则层，符合「只优化 prompt、不换模型」约束）

| # | 改进 | 来源参照 | 落地方式 |
|---|---|---|---|
| 1 | **分阶段字数里程碑**：补「前 300 字抓手 → 前 1500 字卖点 → 前 6000 字主角/世界观落位」阶梯（现只有前 200/500 两档） | Tomsawyerhu | 扩充 `OPENING_MODE_RULES`，按累计字数分档注入 |
| 2 | **钩子类型化**：让模型先声明开头类型（冲突/悬疑/动作/对话/氛围）与钩子类型（危机/悬念/反转/期待/代价钩），再据此写 | webnovel-write | 写前诊断输出开头类型 + 钩子类型字段 |
| 3 | **三章钩子链条 + 章末断章四式**：从「单章末有无钩子」升级为「绝境切入→反转破局→长线牵引」+ 章末四式（决定/发现/误判/代价） | 行业共识 + reviewer | 强化 reviewer 章末钩子检查为「四式 + 链条」 |
| 4 | **钩子示例库**：仿 `gag_lib` 建 `hook_lib`（开篇/章尾钩子实战范本，含男女频），写作 prompt 注入或免费规则预筛 | tance-mang `hook-library.md` | 新建 `libraries/hook_lib.py` + `libraries/data/hooks.json` |
| 5 | **主角铁律**：明确「第一章主角必须受不公平伤害、用一个动作立人设、禁舔狗/圣母」 | 行业共识 | 写入 `OPENING_MODE_RULES` |
| 6 | **章末钩子不重复**：检查本章钩子与最近 3 章不重复 | webnovel-write | reviewer 规则检查历史章节钩子 |
