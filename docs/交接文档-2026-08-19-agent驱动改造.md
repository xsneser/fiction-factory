# 交接文档：外部 Agent 驱动改造 + 建书向导（2026-08-19）

> 交接对象：下一个接手的开发者 / 外部 agent 会话。
> 本文档覆盖 2026-08-19 全天在「Claude Code skill 层 + MCP 护栏 + 建书向导 agent 驱动」上的全部改造。代码是最终真相，本文档帮助快速定位；冲突以代码为准。

---

## 一、本次交付总览（一句话）

把 NovelEngine 从"Web 手动操作 + 35 个裸 MCP 工具"演进为 **"外部 agent(Claude Code)经 MCP + 命令桥驱动系统界面完成建书→大纲→写作→上架全流程"**——含两个安全护栏(agent 不能直建/删书)、一个浏览器 UI 命令桥(drive_ui)、一个完整的 Claude Code skill 层。

## 二、架构变更（按改动顺序）

### 1. MCP 护栏：create_book / delete_book 移出 MCP 面
- 两个工具改为 **web-only**（`agent_tools.py` `_WEB_ONLY_TOOLS = {"canvas_command", "create_book", "delete_book"}`），**外部 MCP 拿不到**，内部 Web 侧栏 agent 保留。
- **建书必须走系统向导**（`POST /books/start`）：agent 用 `drive_ui` 驱动表单，系统创建。
- **删书走手动**：agent `navigate("/books")` + 用户点删除按钮。
- 效果：注册表 40 工具 / MCP 面 37。

### 2. 命令桥：drive_ui + set_characters（浏览器 UI 驱动）
- `libraries/nav_intent.py`：`push_nav_intent`(kind=navigate) + `push_ui_command`(kind=ui_command)，共用 `_push`（TTL 30s、原子写）。
- `agent_tools.py` `drive_ui(cmd, args)`：白名单 `_WIZARD_CMDS`，写意图队列 → 浏览器 `agent_panel.js` 轮询 → `ne:command` 事件 → 页面 `window.onnecommand` 执行。
- 命令集：`set_field / set_tags / set_characters / pick_candidate / next / prev / load_candidates / skip_candidates / submit`。
- 向导 `start_book.html` 注册 `window.onnecommand`：set_field 需 **DOM + WZ.state 双写**（`show(3)` 用 state.title 覆盖、state.tags 只由 toggleTag 维护）；select 补 option；set_characters 清空列表 + `addCharRow` 逐条 + `collect()`。

### 3. 建书向导第 4 步：删 SSE 管线 → 嵌故事线 Gantt
- 世界观+完整大纲改由 **agent 经 MCP `generate_world` / `generate_full_outline` 生成**（向导不再自动跑两条 SSE，`runWorldGen/sse/feed` 已删除）。
- 第 4 步内嵌 `window.StoryLine` Gantt（`story_line.js/css`），`startStorylinePoll()` 每 2.5s 轮询 `GET /api/storyline/<id>`（新端点）实时填充，phase=ready 自停。

### 4. 角色生成：agent 自动（删向导按钮）
- 新增 MCP 工具 `query_characters`（只读原型库）、`generate_characters`（无书 LLM，原型选择 archetype_ids→tags→genre→启用回退）。
- 删向导「🎲 生成角色候选」按钮 + `POST /api/world-builder/characters` 端点。
- 流程：`query_characters` → `generate_characters` → `drive_ui(set_characters)` 推全 14 字段到页面角色列表。

### 5. 书详情字段透传（本批核心数据修复）
- **人物 14 字段**：`render_characters_prompt` 输出加 `gender/age/death_year/title/brief`；向导 `addCharRow` 用 `data-*` 透传（不渲染输入），`collect()` 从 data-* 读回，不再硬编码空。
- **merge 修复**（`libraries/storyline.py`）：
  - `_deep_keep_existing` 跳过元组加 `0`（age/death_year=0 视为未知，不覆盖 generated 真值）。
  - `_merge_characters` 非 MC 改**按姓名逐字段补全**（existing 空字段由 generated 补、新 generated 追加），不再整组丢。
- **世界观 12 维度**：建书只存 `{description, tags}`，其余 10 维靠 agent `generate_world` 填全——**必须调，跳过即详情页残缺**。

### 6. Claude Code skill 层
- `.claude/skills/`：`novel-master`（主，启动器+调度表）+ `novel-build` / `novel-outline` / `novel-write` / `novel-publish`（分）。
- `CLAUDE.md`：四阶段表 + 路由表 + 护栏 + 状态信号（phase/status）。
- novel-build 要点：世界观候选 = **submit 硬前置**；路线 A 默认（`drive_ui(load_candidates)` → 用户在浏览器点选）；角色 agent 自动生成。
- 手写设计稿 `docs/skill设计思路，人工手写版本.md`。

## 七、硬约束（勿违反）

1. **保持 `deepseek-v4-flash` 模型**，只优化 prompt/生成参数/免费规则层。
2. **护栏**：create_book/delete_book 不得回到 MCP 面；建书走向导、删书手动。
3. **管线不重写**：确定性管线(6 阶段大纲/桥段写作)不自由化；agent 只做决策点。
4. **`_WIZARD_CMDS` 白名单**：新命令必须进白名单 + 页面 `onnecommand` handler，禁止任意 DOM/JS 注入。
5. **数量文档**：改工具后同步 README/mcp_server/CLAUDE/设计文档的 40/37。
