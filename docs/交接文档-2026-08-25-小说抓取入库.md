### 用户决策
- 覆盖**含角色原型库**（用户称「五库」：桥段/大纲/笑点/角色原型；实际系统四库，角色库为后加）。注意：现有 `LibraryIngestor` 只入三库，角色库**无**从小说提取入库链路，需扩展。
- 提取由 **agent 自主**：agent 读参考书 → 提炼桥段/大纲/笑点/角色 → 调薄工具入库。符合铁律「工具内 LLM = bug → agent 自主生成 + save_* 薄工具」。

### 调研结论（可复用）
- **入库面复用**：`FanqieScoutAgent.ingest_selected`（plugins/fanqie_scout.py:1005）纯规则、会 `_save()` 落盘、无需 LLM；web `/api/scout/ingest`（ui/web_blueprints/tools.py:208）正是复用它。
- **提取面** `NovelAnalyzer.analyze_book`（fanqie_scout.py:567）硬依赖 LLM，无 LLM 返回空——因此提取由 agent 自主，工具不调 LLM。
- **库实例**：`plot_lib/struct_lib/gag_lib/char_lib` 来自 `ui/web_blueprints/ctx.py` 单例；agent_tools.py 已 import 前三者，**char_lib 需补 import**。
- 入库字段格式（agent 需按此传）：plot 用 `{name, category, sub_category, structure, slots[{name,options}], notes, word_range}`；structure 用 `{name, total_chapters, stages[{name,description,min_chapters,max_chapters,key_events}]}`；gag 用 `{name, category, pattern_description, fit_scenes, examples}`。
