## 四、核心概念速查

- **phase 状态机**：`storyline.phase ∈ config/outlines/plots/ready`；`book.status ∈ planning/writing/reviewing/finished/published/paused`。写类工具带书级文件锁，冲突抛 `BookBusyError`；`budget_paused` = 预算触发，停下问用户。
- **书锁**：`BookLock(book_id).acquire(timeout=30)`，锁内写元信息 `{pid,ts,purpose}`，锁文件不删（防 TOCTOU）；读不加锁，写走 `write_json_atomic`。
- **双进程协调**：Web 进程与 MCP 进程各自独立 import ctx，靠 `books/` JSON + `storage/` 协调；**勿同时操作同一本书**。
- **skill 双副本同步**：`.dsh/skills/`（运行时）与 `agent-sidecar/skills/`（正本）**必须保持一致**——改 skill 两处都改，否则部署覆盖/漂移。
- **意图队列双通道**：dsh 内部走 SSE 实时；外部 MCP 走 2.5s 轮询兜底；`agent_panel.js` busy 期间暂停轮询防双触发。

## 六、踩坑记录（踩坑备忘）

| 问题 | 根因 | 修复 |
|---|---|---|
| 已完成大纲的书停在 config、反复重跑清空 | `generate_full_outline` MCP 路径从不落 `phase=ready`（最后 on_save 在置位前；Web 路径 done 后再存正常，MCP 漏了） | `outline_generator.py` 完成时先置 `phase=ready`/`generated_at` 再 on_save（2026-08-22，`3d6c274`） |
| 已有大纲被静默清空重排 | `generate_full_outline` 生成时 `tl.outlines=[]`/`tl.plots=[]` 清空重排、无守卫 | 加 `regenerate=True` 参数，已有大纲默认拒绝重跑 |
| 写了桥段写作台不显示 | 写作台只渲染已固化章节，`draft_chapter.json` 不渲染 | `desk.py` 加载进行中草稿为「第N章（写作中）」+ 草稿徽标（`b435757`） |
| `write_next_bridge` 连调被 LoopGuard 熔断 | `_mcp_summary` 键序里 `status` 排最前、`words` 不在元组 → 摘要恒定「status=bridge_written」 | 键序把 `words/word_count/chapter` 提前（`b435757`） |
| 建书 step 卡步 2、表单消失 | agent 漏步 1→2 next / get_build_status 竞态读旧 cur | web 自动进步 2 + 移除每步验证门 + skill 双路径 |
| 步 2 候选被跳过（用户没机会挑） | 单 skill 用 SSE 连发 pick_candidate+next，候选卡瞬间被盖 | **拆两 skill**：`set_candidates` 呈现、挑选是用户动作、「已挑选完毕」才触发建书 |
| 候选卡显示「候选为空」 | `_map_dsh_event` 把 drive_ui 整参 `{cmd, args:{…}}` 当 `ui_command.args`，页面 `args.candidates` 落空 | `_map_dsh_event` 取内层 `args.get("args")`；前端防御性拆包 |
| `drive_ui` 报 `cmd Field required` | dsh/LLM 漏传 `cmd` | skill 加「drive_ui 是两参工具：cmd 必填」；重试 |
| 步 1→2 工具卡过多 | 前置检查+决策点不分路径全跑 | 按钮路径极简：只 `world_candidates`→`set_candidates`，明令禁止冗余工具 |
| 步 3 选材/查询冗余 | 选材决策点+原型查询 | 精简分阶段：选材省略、不 query_characters（原型自动回退）、去前置检查 |
| 工具卡永不 resolve | dsh 不发 tool_result | done/error 收尾所有 toolCards |
| 工具卡无耗时显示 | 实时卡只显示 ✅/❌ | `addToolCard` 记 `performance.now()`，收尾追加 `⏱` |
| 步 3 徽标条残留引用 | 徽标条已从 UI 删除 | skill/文档清理徽标句；`set_*` 处理器去 `updateStageStatus` |
| `.dsh` skill 改了正本没改 | `.dsh/` gitignore、`agent-sidecar/skills/` 才是正本 | 改 skill 两处同步；交接/架构文档列双副本规则 |
