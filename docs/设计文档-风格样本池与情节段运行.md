# 设计文档：样文池（StyleSamplePool）与情节段运行（Plot Run）

> 日期：2026-09-06　定位：实现规格。本文描述**实际落地形态**（含 2026-09-06 已提交的 dims 加权随机选择器），供写作侧/后续改造对照。
> 配套：`docs/架构与故事线模型-情节弧情节段关系.md`（术语总图）、根 `CLAUDE.md`、`NOVEL_AGENT.md`（写作指令）。

## 一、目标一句话

写作 agent **每次情节段运行（Plot Run）只拿到一篇与该段场景/性质匹配的人工样文**：规则层按当前情节段的 dims 语义 query，在词条池里**受约束加权随机抽 1 篇**（命中窗放宽 + 近期避重 + 跨任务持久化），使同一作者每次生成的语言参考有小漂移，但不跑偏场景、不用"整池无差别随机"。

```
get_writing_context(book_id)
   → next_plot（draft-aware 下一个未写情节段）+ plot_run（本段/弧目标/线程状态/承诺/字数余量）
   ↓ agent 按 plot_run.plot 判 dims，组成 query
get_pen_style(book_id, query=query, k=1)
   → 命中窗放宽(温度) → SEL_WEIGHTS 软加权 → 加权随机 → 近期避重(进程内∪持久化) → 抽 1 篇渲染
   ↓ style_rules = 笔名 md(负约束) + 渲染的【单篇】STYLE REFERENCE
   ↓ agent 生成本段正文 → save_plot_draft → 章满 save_chapter_text(plot_segments=[…])
```

## 二、词条多维权表 dims（既有实现，沿用）

`StyleSample` 词条带 `dims`（英文键 8 维权表，缺维=选择器通配）：
`scene[]/narrative_action[]` 多选；`dramatic_state/cast/dialogue_density/information_density/pace/pov` 单选。
`/samples` UI 多维编辑；词条仍保留中文 `scene_tags`（过渡期 / 展示）。库现 25 条、每场景 3–5 条。

## 三、`pick_samples`（加权随机选择器，`libraries/style_samples.py`）

```python
pick_samples(samples, query=None, k=3, avoid=None, rng=None, temperature=1.0)
  → (picked: list, meta)
```

- `query`：只认 `SEL_WEIGHTS` 的维；样本缺某维=通配（不过滤也不加分）。
- **硬过滤 → 软加权**：`SEL_WEIGHTS = {scene:5, dramatic_state:3, narrative_action:3, cast:2, dialogue_density:2, information_density:1, pace:1, pov:1}`；多选维按命中数计权，单选命中计权。
- **命中窗放宽（temperature，本次新增）**：精确命中为空时，允许沿**最低权重声明维**逐级丢弃最多 `int(temperature)` 个再试——候选留在「同场景附近」（scene 权重最高最后才丢），**不做命中集外无差别随机**；全放开仍空才走整池兜底（`_fallback_pick`，meta.fallback=True）。meta 记 `relaxed_dims`。
- **近期避重**：`avoid` 里的样本 ×0.5（软避重，不绝对禁止）。
- 加权随机轮盘不放回取 k；`rng` 可注入（测试复现）。

## 四、近期避重历史（本次新增，跨任务持久化）

- 进程内 `_STYLE_RECENT`（dsh 单任务内跨情节段自动避重，max 12）∪ **按笔名持久化** `storage/style_samples/pick_history/<profile_id>.json`（entries=[id…] 旧→新，max 10）。
- `style_samples.load_pick_history(profile_id)` / `record_pick_history(profile_id, sample_ids)`；写走 `core.json_store.process_file_lock` + `write_json_atomic`，失败静默降级（不阻断注入）。
- 接入点 `get_pen_style`：把 进程内∪持久化 并上去重后作 `avoid`；`query` 模式抽中后才 `record_pick_history`（**只有真正注入才推进历史**；`get_writing_context` 不触发）。

## 五、`get_pen_style(book_id, profile_id, query, k=3, avoid)` → 单篇注入接线

- 写作侧每次情节段运行传 `query`（dims 语义，由 agent 按本段判断）且 **k=1**（指令层 `novel-write`/`novel-story` 写作规则已写死 k=1："每次情节段运行只注入 1 篇"）；不给 query → 多样封顶（风格概览等非运行调用仍可用）。
- `query` 模式：`build_ref_text_for_profile(profile, query=query, k, avoid)` → `render_reference([picked])` 只渲染抽中的篇目（每条前标 `# 场景:…`）。`ref_summary` 标注抽中 id/类内条数；`samples` 元数据视图给 id/title/dims（无正文），想细看/想多参考用 `get_style_sample` 拉全文。
- md（负约束）单独保留、不参与裁剪；md 模式清空结构化 style/forbidden 数组以压 <8KB。

## 六、PlotRunContext（`get_writing_context` 收敛输入，本次新增）

`agent_tools.get_writing_context(book_id)` 现返回两块：

- `next_plot`（精简兼容块 `{plot_id,name,roles,outline_id}`）——**draft-aware**：第一个 `written_chapter==0` 且**不在当前草稿内**（`_draft_plot_ids` 兼容 `plots`/`bridges` 段落键）的情节段，防章中途重复返回同一首。
- `plot_run`（本段运行收敛上下文，由 `_build_plot_run(tl, p, csm)` 从已 load 的内存 `tl` 现算，csm=character_states 读一次注入 dyn，不加多轮磁盘读）：

```jsonc
{ "plot": { id,name,category,sub_category,words,cover_beats,template_structure,thread_id,order,
            resolves_plot_id,resolves_name,hook_points,theme_hints,roles,outline_id,
            written_chapter,is_payoff },
  "arc_goal": { arc_id,name,notes,arc_path,stage_index,stage_name,stage_desc,stage_events,
                word_span:[start,end], words_left_in_arc },
  "thread":   { id,name,desc,same_thread_written:[{id,name,chapter,role:收局|设局}],
                same_thread_unwritten:[id…], chain_note },
  "promise_state": [ {id,type,desc,status,op,setup_plot_id,payoff_plot_id,deadline_chapter} ],
  "style_query": { scene:[…], cast:… },     // infer_plot_query 按情节段推导，供 pick_plot_sample
  "cast_pack": { protagonists:[…], active:[…], referenced:[…] } }  // 出场角色分级卡（谁在写，2026-09-07 新增）
```

- **场景判定归 agent**：`plot_run` 只给本段事实，不给硬场景提示、不带样文正文——样文注入/历史推进单点在 `get_pen_style`，避免一次运行双抽/历史失真。
- **cast_pack 管角色、样文管语言外壳**：`plot_run.cast_pack`（protagonists=主角全卡/active=其余出场/mentioned/referenced=提及极简）预解析好出场角色的 behavior/speech_profile/当前动态态（`dyn.goal/relationship/arc_stage`…，来自 character_states.json），与单篇样文、笔名风格职责分离；全量角色仍留在 `storyline.basic_info.characters` 作 bible 反查。

## 七、职责分界（防回旧路）

| 概念 | 只回答 | 不做什么 |
|---|---|---|
| 情节弧 Arc | 这一阶段故事朝哪走 | 不管语言 |
| 情节段 Plot（运行单位） | 这一轮写什么（`plot_run.plot`） | 不是"套路"模板 |
| 线程 Thread | 这事还活着吗/上次哪/下次何时（`plot_run.thread`） | **不参与文风/样本选择** |
| 承诺 Promise | 埋了什么、何时兑现（`plot_run.promise_state`） | 只给状态 |
| 角色包 cast_pack | 这一轮**谁在写**（出场角色分级卡：behavior/speech_profile/当前动态态 dyn） | 不管剧情走向、不替判场景、不碰语言外壳 |
| 样本池 Selector | 这一轮恰好像哪种写法（单篇、受约束随机） | 不随机剧情、不替判场景语义 |

## 八、验证

- 纯规则：`pick_samples` temperature=0 只精确命中；放宽时沿低权重维回落、不进整池随机；`record_pick_history` 去重置尾、`load_pick_history` 往返（tools/test_style_sample_pool.py）。
- MCP：`mcp_smoke.py` get_writing_context style_card 断言不回归、get_pen_style style_rules 断言不回归（55/55）。
- 手动 e2e（临时书）：`get_writing_context` 返回 `next_plot`+`plot_run`；`get_pen_style(query={scene:[…]}, k=1)` 只注入 1 篇（ref_summary 单 id）；连续两次同 scene `picked` 不重复（池≥2）；`save_plot_draft`/`save_chapter_text(plot_segments=[…])` 正常落盘。
