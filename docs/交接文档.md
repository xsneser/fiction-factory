## 3. Git 约定（重要）

- 分支：`dev`（工作分支），`master` 为历史。
- 远程：`origin → github.com/xsneser/fiction-factory.git`，**URL 里内嵌了一个 ghp_ token**（会过期/偶发认证失败）。
- 直连 GitHub 经常超时，**已配置仓库级代理**：
  `git config http.proxy http://127.0.0.1:7897`（取消：`git config --unset http.proxy`）
- 推送失败先看是不是网络：`git push origin dev` 重试即可；报 Authentication failed 就是 token 问题，让用户换 token。
- 本会话习惯：**每完成一步提交一次并推送**，用户明确要求。提交信息用中文 conventional 风格（fix/refactor/chore + 简述）。

## 6. 坑与注意事项

- **四大库是进程内单例**：改了 `libraries/data/*.json`（或删了让内置生效）必须**重启服务**才生效。
- **api.json 是明文 Key**：gitignored，别 `git add -f`；日志里也确认过没有泄露。
- **测试会动数据**：`test_all` 会创建并删除测试书（书名「系统修仙录」）；`books/`、`profiles/` 是用户真实数据，别删。
- **删除类操作**：`delete_book`/`timeline_delete` 等接口无回收站，前端只有 confirm；帮用户做删除前先确认。
- **服务重启后**：`_engines` 缓存清空，旧引擎会话失效，前端会提示重新进入写作台（正常现象）。
- 修复「文章被截断」类问题要小心：笑点注入函数现在要求输出 ≥ 原文 90% 才接受，别改回 `text[:2000]` 的截断写法。
