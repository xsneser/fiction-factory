## 一、背景与目标

2026-08-25 侧栏 dsh agent（deepseek-v4-flash）建书出现连续数据问题，复盘 `storage/task_events.jsonl`（事件流）定位到一条链：

**agent 不按契约传工具参数 → 前端校验/渲染崩溃或静默丢字段 → 落库坏数据（全员主角、主角识别错、角色丢失、rules 丢失、故事线桥段/大纲不显示、直接建书）**

本轮修复三线：**① 规则层把参数契约写死（模型照做）② 前端兜底（模型再犯错也不崩/不塌）③ 建书前确认门（不误建书）**。

## 二、根因链（复盘发现）

| # | 现象 | 根因 |
|---|---|---|
| 1 | 空参探测参数（`set_outline`/`set_characters`/`set_field` 各 1+ 次失败调用） | `drive_ui` 工具描述没列每命令必填 args → 模型靠猜 |
| 2 | `set_world` 顶层键写 `world`（非 `world_building`）→ 被拒 | 契约没写顶层键名 |
| 3 | `set_characters` role 传自由文本（女主/宿敌/左膀右臂…）→ 前端 role select 无匹配默认选「主角」→ **7 人全变主角 → `get_mc` 命中反派** | role 枚举未写进契约 |
| 4 | `relations` 传字符串 → `appendCharCard` `(relations||[]).forEach` 崩溃 → `renderCharCards` 中断 → **只留第 1 个角色** | relations 格式未写 + 前端不兜底 |
| 5 | `rules` 传字符串 → `worldToForm` `(rules||[]).join` 崩溃 → rules 落空 | 同上 |
| 6 | `set_outline` outlines 没 `id`/用 `description`、plots 没 `outline_id`/`order` → StoryLine 按 `outline_id` 归组、按 `o.id` 关联，全空 → **桥段全被丢、大纲全空** | set_outline schema 未写 + 前端不归一化 |
| 7 | agent 填完表单直接 `submit` 建书进详情页 | 缺建书前确认门 |

## 三、修复清单

### 规则层（NOVEL_AGENT.md，agent 每任务注入，**无需重启**）
- **建书参数契约**：`set_characters`（role 只取 `主角/配角/反派/其他`、`importance` 必传主角=1、`relations` 必须 `[{name,relation}]` 数组）；`set_world`（顶层键必须 `world_building`、`tone/target_audience/pov/era_language` 放顶层、`rules` 必须数组、不用 `setting/target_reader` 非标准键）；`set_outline` schema；步 3 **禁用** `set_candidates`/`pick_candidate`。
- **set_outline schema**：outlines `{id, name, start_chapter, end_chapter, notes, stages?}`（`id` 唯一必填、备注用 `notes` **非 `description`**）；plots `{id, name, outline_id, order, category?, thread_id?, roles?, template_structure?}`（`id` 唯一必填、`outline_id` 必填指向所属大纲 id、`order` 卷内序号）。
- **建书前确认门**：填完步 3 表单**停下，向用户汇报设定概要，等确认后再 `submit`**（不确认不建书）。
- 步 3 分阶段流程 ↔ 命令对照（前→大纲→核心矛盾→势力→桥段→人物→补全→确认）。

### 工具描述（`agent_tools.py` drive_ui docstring，**重启生效**）
- 每命令必填 args 清单 + 角色/键位/relations/rules 类型 + **`submit` ⚠️ 调用前必须先向用户汇报并取得确认**。

### 前端（`ui/templates/start_book.html`，**重启生效**）
- `normalizeCharRoles`（set_characters 渲染前）：role 非枚举→按 importance 推断（=1→主角否则配角）；importance 缺省→由 role 定；无主角→传入顺序第一个兜底。
- `set_world` 键位归一化：`world_building` 里的 `tone/target_audience/target_reader/pov/era_language/setting` 拆到顶层/标准位置，删冗余键。
- `normalizeOutlineData`（set_outline）：outline 补 `id`/`notes`（description 兼容）、plot 补 `id`/`order`/`outline_id`（无归属按序均分）。
- 类型兜底：`appendCharCard` relations 非数组跳过（不再崩）；`worldToForm` rules 字符串直接用（不再崩）。

### persona 同步（改 `_PERSONA` 需**四处一致**）
`libraries/dsh_bridge.py` `_PERSONA`（源头，运行期 overlay 自动生成）＋ 镜像 `agent-sidecar/cordis.patch.yml`、`~/.dsh/profiles/headless/cordis.patch.yml`、`vendor/dsh-ne/node_modules/@deepseek-ai/dsh-headless/cordis.patch.yml`。改完重启 58080。

### 存量数据
- `books/book_002/storyline.json` 已归一化：5 大纲补唯一 `id`、10 桥段分布到各大纲（各 2）+ `order`。**⚠️ 大纲 `notes` 已丢**——agent 传 `description` 被 OutlineSlot 丢弃，补不回原文，需走大纲阶段重生成。
