## 一、最值得关注 ⭐⭐⭐⭐⭐

### Nigh/show-me-the-story ⭐ 398 🔥🔥🔥

- **链接**：https://github.com/Nigh/show-me-the-story
- **语言**：Go + Svelte | **更新**：2026-07（活跃）
- **描述**："Self-hosted AI novel generator. Single Go binary + web UI. OpenAI-compatible API → outline → chapter-by-chapter writing with review, foreshadowing, fact-check, and full-book polish. Chinese & English."
- **Tags**: agent, ai-writing, novel-generator, foreshadowing, self-hosted, single-binary, web-novel
- **评价**：**跟你的设想最接近！** 单文件部署 → 大纲 → 按章写作 → 审查 → 伏笔检查 → 全书打磨。开源、自部署、支持中英文。唯一的遗憾是 Go 写的不是 Python。**必看项目。**

### BlinkDL/AI-Writer ⭐ 3808

- **链接**：https://github.com/BlinkDL/AI-Writer
- **语言**：Python | **更新**：2025-05（停更）
- **描述**：AI 写小说，生成玄幻和言情网文。基于 RWKV 模型（类似 GPT-2）
- **评价**：最老牌中文网文生成。但旧模型路线、已停更

### xiaoshengxianjun/51mazi ⭐ 412 🔥🔥

- **链接**：https://github.com/xiaoshengxianjun/51mazi
- **语言**：Vue/Electron | **更新**：2026-07（活跃）
- **描述**："我要码字，这可能会是最好用的小说写作软件"。集成：随机取名、地图设计、关系图谱、人物档案、时间线、AI 写作、AI 生成封面、AI 生成人物图、网文下载
- **官网**：https://www.51mazi.com
- **评价**：**功能最完整的桌面写作软件**。但方向是"人手写+AI辅"，不是"批量全自动生成"

### alfredxw/denova ⭐ 529

- **链接**：https://github.com/alfredxw/denova
- **语言**：Go | **更新**：2026-07（活跃）
- **描述**：AI creative platform for novel writing and RPG. AI agents, subagent workflows, automations, image generation, version control
- **Tags**: agent, ai-agents, ai-tools, ide, novel
- **评价**：功能最全面的 Go 生态创作平台。Agent 架构思路有参考价值

## 五、市场定位结论

1. **"大纲→仿写→全书→多书矩阵"这个链路上，你独一份**
2. **show-me-the-story**（398⭐）是大纲+章节流程做得最好的开源项目，Go 语言，建议细读其架构
3. **51mazi** 是写作工具"体验"做得最好的，参考它的功能设计
4. **novel-writer-master**（5⭐）是 Python+Streamlit 的最接近原型，代码量小，适合快速参考
5. **novel-studio**（1⭐）是 Python 多 Agent 写作的最新活跃项目
