# 实例：十日终焉 → 枫落（2026-09-05）

首个全流程实例。目标笔名 profile_001 枫落（原：都市爽文吐槽打脸）。参考书《十日终焉》（storage/novels/十日终焉，uukan 合并抓取，1496 章）。

## 0. 量化表（style_scan.py，取样 前20+300/800 各20 共 60 章，12.4 万字）
- 引号体系：对话用全角 “”；强调/概念/术语/拟声用直角引号 「」（1227 次）；圆括号（≈0，多为抓取页脚残留）；无单引。
- 句末标点：。3305 / ？1133 / ！仅 352 / …1644（省略号极多）/ ；2 / ：262。
- 句长：均值 19.3、中位 15、≤6 字占 32%（p90 44）——短句为主 + 偶发长句（数值以 `scripts/style_scan.py 十日终焉` 实测为准）。
- 段落：单句段占 48%；每千字句数 51.8；对话占比 ~41%。
- 语词密度（>0.5/千字）：说道 3.7、开口 0.7、问道 1.1、但 1.6、所以 0.9、可是 0.8、毕竟 0.6、应该 0.7、难道 0.4、
  缓缓 0.4、似乎 0.6、忽然 0.5、居然 0.2、仿佛 0.1。≈0 的：然而 0.0/因此 0.0/顿时 0.0/只见 0.1/不禁 0.0/
  与此同时 0/就在这时 0/转眼间 0/冷声 0/微微一笑 0。粗口 卧槽/淦/牛逼 = 0。
- 结论：①放开 缓缓/似乎/忽然/居然/仿佛/竟然（源文自然用）；②禁 然而/因此/与此同时/顿时/只见/不禁/微微一笑/
  眼中闪过一丝 等（源文避用 + AI 俗词）；③禁破折号——（正文几乎不用）；④句长不设死区间，要短长错落。

## 1. 目标形态
- 把枫落切成「冷感克制·悬疑推理」人格：幽默=冷感克制(不吐槽)、动作=动词化白描、钩子=断在揭示/设问、节奏=紧凑悬念(非打脸爽点)。
- 7 条**句式风格卡片规则逐轮重建为最终 20 prefer + 15 ban**（见下「最终库」）。

## 2. 分轮演进（每轮 = 改规则 → dsh 重写样章 → style_cmp 对比 → 人读）
| 轮 | 规则增量 | 样章结果 |
|---|---|---|
| R1 | 总基调克制/禁粗口/「」强调/禁圆括号/短句… 首次整库重建 | 克制到位但「」=0、设问少、句太碎 |
| R2 | +「」独立短段 / 省略号留白 / 中长句垫底+推理连接词 / 设问收束 | ch1 设问/省略号升；句号入「」出现 |
| R3 | +句号放「」外 / 说道·问道前引标签 | ch2 句号入「」=0、说道/问道出现 |
| R4 | +日期整段括勿拆（「2050年3月14日」）；禁破折号—— | 「」密度 20→6；日期间不再拆单字 |
| R5 | （同日）重写验证破折号=0 | 全维对齐：设问 12=12、…6=6 |
| R6 | 断句修复：删「≤15字短句为骨」→「整句串块 20-35 字」+「逗号语义(名词短语内不逗)」 | 句/千字 58→45，但**句式公式化**(每行都是 X，Y。) |
| R7 | 断句再修：句读规则改为「反公式·错落」(短句5-12字无逗 + 两句一逗 + 3-5逗号块长链 35-55 字交替；句号随语义) | 人读认可：长短错落、长链/短句交替、末段长流收束 |
| R8/R9 | （记录于 `docs/研究文档-人工vsAI网文误判指标.md`）复指句号硬切/无推进元描写/跳读 三条硬伤固化 prefer_28/29/30 | 人味变体仍"不像"，定"消除硬伤+非均匀个人词频"为稳定方向 |
| R10 | 叙述层人称代词克制·主语承前省略(prefer_31)——详见 `docs/研究文档-R10-…代词与写作差异.md`；`style_scan.py`/`style_cmp.py` 新增代词分层密度维度 | 重写 ch1 叙述代词 27.5 → **14.7**(对齐参考 14.3)；⚠️ 附带回归=对话引号变 ASCII 直引号 |

> 教训：断句/节奏规则绝不能给死字数区间——「短句为骨」→碎；「串成 20-35 字」→每句同形两段公式化。
> 最终用「反公式·错落 + 语义混排」语义描述，人读定稿。
> R10 教训：代词密度必须分「叙述层/对话层」且各层以自身汉字为分母——第一版按全文稀释会得出假结论；对话内 我/你 正常，问题只在叙述层句句显式挂主语。
> 引号治理（R10 后续）：规则例句里凡「引一整句/示例句/对白」的，别用「」包（会教模型对白上「」，如 ch12 整章对白写成「」）；统一用全角“”引示例句。已改 prefer_1/20/23/31 + ch12。
> 「」语义再收窄（用户 2026-09-05）：直角引号「」= 专有名词/具名专指 only（如 末羊/望舒号/第八天/人羊），不用于数字/年份/日期/普通强调词/拟声 → 改写 prefer_5/16/20/22，顺带**废除 R4 的「日期整段括」**。已写章节未清洗（只改规则，防逐章人审成本）。

## 3. 最终库（枫落 = 20 prefer + 15 ban；可作下次仿写起点）
prefer 主题（每条是长句含例句，写入风格卡给 dsh）：总基调克制无粗口 / 对话占比四成·全角“”前引 /
「」=专有名词·禁（） / 对话标签中性(说道问道开口) / 转折但可不过 + 推理连接词(这说明按理说换句话说难道…) /
心理走观察推断少心想 / 具体动词·可自然用 缓缓似乎忽然居然仿佛 / 章末断在揭示设问 / 设问收束推理段 /
省略号留白 / 中长句垫底 / 「」句号放外 / 对白全角“”·数字日期不括 / 句式错落·反公式（短+中+长链 3-5 逗号块交替，
忌每行「X，Y。」）。
ban：然而/因此/与此同时/顿时/只见/但见/不禁/不由得/微微一笑/眼中闪过一丝（带替换自动去AI味）+
就在这时/转眼间/值得一提/值得…的是/——（空替换硬禁）。

## 4. 关键坑（流程级，已并入 SKILL.md）
- 直改 style_rules.jsonl 不热载 → 用 MCP add/delete 或 build_rules_replay.py 一次性写；dsh 新任务(新进程)才读到。
- test_all.py 非幂等重写 style_rules.jsonl（风格测试段）→ 别为验证跑；会被并行窗口的 test_all 还原到基线。
- 并行窗口还原文件：随时用 replay 重放；改前 cp .bak。
- 换人格/整库清空重建 = Modify Shared Resources，权限分类器拦（选项标签「是」不够）→ 先 AskUser 点名再动。
- 杀卡死 dsh(node) 只能杀自己触发的且 PID 经用户确认。
- 禁词放开以源文词频为准；硬禁(空替换)别滥防 save 误伤拒稿。
